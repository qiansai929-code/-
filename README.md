# 📷 摄影项目看板

一个专业的摄影项目管理应用，支持看板、表格、日历三种视图。完全本地化存储，无需服务器。

## ✨ 功能特性

- 📋 **看板视图** - 拖拽管理项目状态（待拍摄→拍摄中→已交付）
- 📄 **表格视图** - 数据列表查看和按状态筛选
- 📅 **日历视图** - 按日期查看项目安排，一目了然
- 📊 **统计面板** - 实时进度总览和本月业务数据统计
- 📥 **Excel导入** - 自动识别列名，快速批量导入项目数据
- 📤 **Excel导出** - 随时导出项目数据为Excel格式
- 🔐 **权限管理** - 管理员和访客两种模式
- 💾 **本地存储** - 数据保存在浏览器，隐私安全

## 🚀 快速开始

### 直接使用
1. 下载或克隆本仓库
2. 在浏览器中打开 `拍摄日程/index.html`
3. 选择登录方式：
   - **管理员模式**：输入密码 `admin123`（获得完整编辑权限）
   - **访客模式**：点击"以访客身份查看"（仅查看权限）

### 在线使用
访问 GitHub Pages：https://qiansai929-code.github.io/-/拍摄日程/

## 📝 数据字段说明

| 字段 | 说明 | 必填 |
|------|------|------|
| 客户名称 | 项目客户名称 | ✅ |
| 区域 | 拍摄地点/区域 | - |
| 甲方 | 委托方/甲方公司 | - |
| 制作要求 | 具体的拍摄或制作需求 | - |
| 拍摄天数 | 需要多少天完成 | - |
| 人数 | 参与人员数量 | - |
| 执行设备 | 使用的摄影设备 | - |
| 拍摄日期 | 项目开始日期 | - |
| 状态 | 待拍摄/拍摄中/已交付 | ✅ |
| 备注 | 补充说明信息 | - |

## 📥 Excel导入指南

### 支持的格式
- `.xlsx` 和 `.xls` 文件

### 自动列名识别
应用会自动识别以下列名变体（不区分大小写）：

| 标准字段 | 可识别的列名 |
|---------|------------|
| 客户名称 | 客户、名称、项目、公司 |
| 区域 | 区域、地区、城市、地点 |
| 甲方 | 甲方、委托、发包 |
| 制作要求 | 要求、制作、需求、内容 |
| 拍摄天数 | 天数、天、工期 |
| 人数 | 人数、人员、团队 |
| 执行设备 | 设备、器材、无人机、相机 |
| 拍摄日期 | 日期、时间、拍摄日 |
| 状态 | 状态、进度 |
| 备注 | 备注、说明、补充 |

### 导入步骤
1. 管理员登录后点击 "📂 导入" 按钮
2. 拖拽Excel文件到上传区或点击选择文件
3. 在映射弹窗中确认列名映射
4. 点击 "确认导入" 完成导入
5. 自动检测重复项（同一客户同一日期视为重复）

## 📤 Excel导出

点击 "💾 导出" 按钮，所有项目数据将导出为Excel格式，文件名为 `摄影项目_YYYY-MM-DD.xlsx`

## 🎯 状态流转

```
待拍摄 → 拍摄中 → 已交付
```

- 在看板视图中，可通过拖拽卡片在列间移动，快速更新状态
- 也可在卡片上点击对应按钮快速流转状态
- 任何状态都可编辑修改或回退

## 🔄 操作说明

### 管理员操作
- **新建项目**：点击 "＋ 新建" 添加新项目
- **编辑项目**：点击卡片上的 "编辑" 按钮
- **删除项目**：点击 "删除" 按钮（确认后删除）
- **导出数据**：点击 "💾" 导出为Excel
- **清空所有**：点击 "🗑️" 清空数据库（谨慎操作）
- **拖拽更新**：在看板视图中拖拽卡片以更新状态
- **搜索筛选**：使用搜索框按客户名、区域、甲方等关键词筛选

### 访客操作
- **查看项目**：查看所有项目信息
- **切换视图**：在看板、表格、日历视图间切换
- **搜索筛选**：使用搜索和筛选功能

## 📊 统计面板

### 进度总览
- 显示项目总数
- 圆形进度条展示各状态占比
- 分别统计：待拍摄、拍摄中、已交付

### 本月业务
- 已交付：本月完成的项目数
- 进行中：本月进行中的项目数
- 待拍摄：本月待拍摄的项目数
- 本月总计：本月项目总数

## 💾 数据存储

- 所有数据存储在浏览器 `localStorage` 中
- 数据持久化存储，关闭浏览器后数据仍保留
- 完全隐私安全，不上传到任何服务器
- 清除浏览器数据时会清除应用数据

## 🔐 安全提示

- 默认管理员密码为 `admin123`，**首次使用建议修改**
- 修改密码需要编辑 `app.js` 中的 `PWD` 变量
- 访客模式仅具有查看权限，无法修改数据

## 🌐 兼容性

- 支持现代浏览器（Chrome、Firefox、Safari、Edge）
- 支持移动端设备（响应式设计）
- 支持 iOS 添加到主屏幕（PWA功能）

2. 选择 "添加到主屏幕"
3. 即可像原生应用一样使用
